# 路线图

用户当前目标是主流数据库通用管理工具，并明确保留已有 SQL Server。产品完成标准见 [PRODUCT_ACCEPTANCE](PRODUCT_ACCEPTANCE.md)，范围与接入标准见 [DATABASE_SCOPE](DATABASE_SCOPE.md)；规划项不算当前能力。

| 阶段 | 范围 |
|---|---|
| V0.1.0–V0.2.2 已归档 | 原生工程、SQL Server 工作台、安全单行编辑与驱动源码适配 |
| V0.3.0 已归档 | 统一多数据库会话和连接配置；MySQL/MariaDB/PostgreSQL 只读工作台；SQLite 文件副本浏览；旧配置迁移 |
| V0.4.0 已归档 | Redis/Valkey 只读键值工作台；首页连接体验；查询收藏、当前页 CSV 导出 |
| V0.5.0 已归档 | MongoDB 集合、受限筛选、文档游标分页；独立认证数据库与升级 |
| V0.6.0 已归档 | Elasticsearch/OpenSearch 索引、映射、受限 DSL 与分页；搜索连接表单与升级 |
| V0.7.0 已归档 | 服务器扫描、按权限发现数据库、筛选选择后连接；入口库及逻辑库语义 |
| V0.7.1 已归档 | 已接入网络引擎的证书预览、指纹确认及 IP/自签名连接 |
| V0.7.2 已归档 | 移动连接界面、引擎分类卡片、可见证书入口与扫描单选列表 |
| V0.8.0 已归档 | 可选加密密码、SQL 表格单元格编辑、Tab 补全与持久化设置 |
| V0.8.1 已归档 | 连接后对象加载修复、可见对象列表、表收藏、历史连接一键进入 |
| V0.9.0 已归档 | 三种 AI 文本协议、模型获取、上下文预览、SQL 草稿；宽表字段分组、全屏与行详情 |
| V0.9.1 已归档 | SQL Server 日期字段读取断连修复；独立 AI 设置、使用与配置分离；搜索字段属性、主键筛选和字段名复制 |
| V0.10.0 本轮 | 固定数据 / SQL / 结构工作台、数据库搜索选择、双指缩放、日期安全编辑、显式生产编辑与实时 AI 建议 |
| 下一批 | Release 驱动适配与真机验证；随后多查询标签及 ClickHouse |
| 后续接入 | Oracle、Db2、国产数据库、兼容协议服务、分析/时序/图/文件数据库；逐项验收 |
| 能力补全 | 各 SQL 方言安全编辑、全量受控导出、对象搜索、AI 云认证及 Responses 协议 |
| 持续发行门禁 | 驱动 R8 适配、真机/arm64、稳定性、正式身份/签名、升级回归 |

SQL Server 功能保留并回归。新增数据库优先扩大真实读能力，再按引擎补全写能力；主流覆盖与稳定发行是两条同时推进的工作，不将实验性 Debug 当作正式兼容声明。

## V0.11.0 本轮范围

完成列头筛选排序、数据库端参数化分页视图、缩放行距修复、AI 当前表受限查询与 SQL Server 单条写入预览。真实服务器和 Android 验收见本版 TEST_REPORT；正式 Release/R8、真机、更多引擎写入仍为后续任务。
