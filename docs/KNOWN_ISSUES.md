# V0.14.0 已知限制

1. **发行**：本版使用独立正式签名和混淆 Release；真机、arm64、各厂商设备及其它服务端版本尚不能从模拟器测试推断。实际本轮结果见 TEST_REPORT。历史 Debug 签名不能直接覆盖升级；卸载会丢失本地数据，目前无完整迁移工具。
2. **覆盖**：十种引擎有实现；不是所有数据库都已接入。Oracle、Db2、ClickHouse 等仍在规划中。驱动兼容不等于所有服务商和版本均经过实测。
3. **关系型写入**：需要稳定主键与完整可比较原行，无主键、视图、启用触发器、超过 64 列和复杂类型仍受保护。字段最多 4000 字符，页总文本预算 256 Ki 字符；超限不截断提交。MySQL/MariaDB 仅 InnoDB，并要求能检查触发器；角色间接授权可能保守判为只读。不是任意 SQL 写入控制台。
4. **并发**：短事务只在提交时开启；SQL Server 使用表锁，可能阻塞其它操作。分页不是数据库快照。所有确认单次有效，超时/失联结果不明确时需核对，不自动重放。数据库默认值、外键和服务端规则仍生效。
5. **SQLite**：只编辑导入的 64 MiB 内一致性非 WAL 私有副本，不改源文件；尚无修改后副本的文件导出功能。NUMERIC 动态类型、BLOB、虚拟表和生成列等仍有编辑限制。
6. **Redis/Valkey**：单节点 RESP2/TLS，六类键可读，仅完整加载的 UTF-8 字符串可写；不支持集合成员编辑、集群/Sentinel、模块或任意脚本。写入需 WATCH/MULTI/EXEC 与 KEEPTTL。SCAN 不是快照。
7. **MongoDB**：单地址 SCRAM-SHA-256，有界完整文档编辑，完整原文与 BSON 类型检查。带点号或 $ 字段、复杂或超限文档可能只读；当前原子谓词需要 MongoDB 5.0+。无副本集发现、SRV、云认证、聚合、跨文档事务或导出。超时不重试。
8. **Elasticsearch/OpenSearch**：Basic HTTPS、有界索引范围、100 条分页，最多前 1000 条。单文档原生版本校验；不提供 bulk、脚本、索引管理和搜索导出。无版本号或未展开的文档不可编辑；ID 为 `.` / `..` 或包含 `/`、`\`、`%` 的文档禁止直接写入，避免 HTTP 路径归一化改变目标。OpenSearch 单文档写入还需要安全插件对应的 cluster bulk 动作权限及目标索引写权限，服务端仍执行授权检查。
9. **AI**：三种文本接口与 19 个地址预设，不是逐家认证；无真实计费密钥测试。AI 操作限当前关系型表；只有 SQL Server 支持受限整表删除。记忆本地加密，最多 50 个上下文、每个 16 轮；发送最多 8 轮及总 24000 字符，无跨设备同步。不会把过往操作描述当作执行成功。
10. **表格**：无多格粘贴、批量提交、Excel 公式、整表无限加载或 JOIN 结果编辑。完整备份不能由当前页 CSV 替代。applicationId 沿用历史版本，本版首次使用独立正式签名；凭据和记忆随卸载或 Keystore 丢失可能无法恢复。

11. **驱动扩展**：本版仅适配应用公开的连接路径，不提供 GSS/Kerberos、云 IAM/令牌、XA、JNA 本地传输、MongoDB SRV/自动字段加密等桌面扩展；这些入口明确拒绝，不静默降级认证或 TLS。详见 DRIVER_RELEASE_PLAN。
