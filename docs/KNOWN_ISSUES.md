# V0.12.1 已知问题与未验证项

## V0.9.1 日期字段修复

已在合成 SQL Server + Android 上定位 V0.9.0 日期读取触发 NoSuchMethodError。源码适配修复后的执行结果见 TEST_REPORT；未访问用户业务服务器，也未将此修复宣称为所有未知类型均受支持。V0.10.0 增加六类日期字段精确编辑，仍受主键、触发器、完整行读取等条件限制。

1. **覆盖仍在扩展：** 当前十种连接类型有实现，除 SQL Server 外均只读；Oracle、Db2、ClickHouse等范围见 DATABASE_SCOPE，尚不可连接。目录不是兼容承诺。
2. **Release 阻塞：** R8 仍缺少 Android JDBC/JNDI/XA/management 及可选云认证等 API；本轮仍报告 193 项缺失类，与 V0.7.0 相同，其中包含 50 项 MongoDB 可选运行时依赖（Netty、Unix socket、加密等）。没有 Release APK，未添加批量 dontwarn。Debug 实连不能替代正式发行门禁。
3. **系统范围：** 只对测试报告列出的服务器版本与 API26/API30 x86_64 模拟器作声明；未验证真机、arm64、云厂商认证、多版本服务器或大库性能。
4. **写入：** 仅 SQL Server 显式开启的会话开放安全类型单行编辑（包括生产标记连接）；视图、无主键、启用触发器、复杂类型组合只读。新增引擎没有写 SQL/DDL/图形编辑。SQL Server 短事务使用表锁，可能阻塞其他写入。
5. **只读边界：** PostgreSQL/MySQL/MariaDB 每操作重设服务端只读事务；仍须最小权限账号。函数、扩展、临时表和外部系统副作用不能仅由 SQL 语法或事务只读保证；不应使用管理员账号浏览不可信 SQL。
6. **结果限制：** 每页 100 行、每组 64 列（表可切换字段组，查询仅前 64 列）、每字段 2048 字符/256 字节二进制、总字符预算；JDBC 驱动内部缓冲与 SQLite CursorWindow 另有限制，不宣称应用堆的硬上限。复杂类型标记未加载，超大查询可能直接失败。分页不是一致性快照，无主键只显示首批。
7. **SQLite：** 64 MiB 私有副本，拒绝 WAL 格式主文件，须先导出完整一致性文件。系统 SQLite 版本不同，较新文件特性可能无法读取。只读且不写回；删除连接不会自动删除共享副本，暂未提供文件清理界面。
8. **方言：** 单条受限 SELECT；无 CTE、多语句、变量、美元引用、反斜线转义、可执行注释、DDL、批量事务。PostgreSQL 每个连接绑定一个库，元数据查询使用当前已测试系统目录，旧版服务器需独立验收。
9. **安全连接：** 默认系统 CA 或连接专用公共 CA，严格证书链/主机身份；也可显式确认具体服务器证书指纹，详见 CERTIFICATE_TRUST。首次信任需独立核对指纹；SQL Server 自动证书可能在重启后变化，需要重新确认。不支持明文端口，未启用 TLS 的 Redis/MongoDB/搜索服务需要先配置服务端 TLS。暂无 IPv6、mTLS、Windows/Kerberos/Entra、云 IAM、多主机故障转移。PostgreSQL 认证采用 pgjdbc，受限登录预算不等于所有设备时延保证。
10. **状态与发行：** 取消/断网不证明服务端停止，未知写入不重放。真正进入后台断开；旋转配置重建保留会话，可选加密保存密码，页面内 String 内存不可保证擦除。com.example.datasail 为占位，保持本地 Debug 签名；GitHub 提供预发布 Debug，不能等同稳定正式发行。全表导出与数据库备份尚未实现；具有显式查询收藏、进程内查询历史和当前页 CSV。

11. **Redis / Valkey：** 仅单节点 RESP2/TLS 与 ACL 用户，支持六类键只读预览；无集群/Sentinel、模块、写入及任意命令。SCAN 是游标而非快照，COUNT 非严格页长。响应超限会关闭连接。JVM 系统 DNS 解析可能不立即响应取消，但已作废回调不能复活会话。
12. **CSV 与收藏：** 收藏保存显式 SELECT 草稿及 SQL 表的连接/库/Schema/名称标识，不保存数据行；用户应自行确认无业务密钥。CSV 最多当前页，NULL、反斜杠和公式前缀采用 WORKSPACE 约定；第三方表格软件可能自行改写类型。系统文件选择器会触发断开，写文件失败可能留下部分文件。第三方文件提供者/真机尚未验收。

下一项最小闭环：解决 Release/R8 并验证真机，随后 SQL 多标签；引擎扩展继续按独立验收接入 ClickHouse；同步继续解决驱动 R8 与真机门禁。主流引擎逐项接入，不能将当前版本称为“全数据库兼容”。

MongoDB 当前限定单个地址直连、SCRAM-SHA-256、库内集合只读。尚无 SRV/副本集发现/分片路由、云认证、DocumentDB 兼容声明、写入、聚合或文档导出。服务器游标不是快照，闲置或网络中断后需重新查询；超大文档仅显示未展开。官方 Java 驱动不等于官方 Android 支持，当前属于独立实验性适配。

搜索工作台仅 HTTPS + Basic、单地址、普通非隐藏索引，索引名需为小写字母/数字开头及字母/数字/点/横线/下划线。连接范围支持 `*`，不支持多范围、别名展开、数据流、URL 路径前缀、SigV4/API Key/mTLS。索引列表最多 200 项；查询条件最多 8000 字符，支持 match_all/term/match/range/bool，无任意端点、脚本 DSL、聚合或写操作；服务器已有 runtime field/分析器/插件的行为仍由服务器配置决定。分页按 `_doc`/from，不是快照，索引变化可能重复或遗漏；最多前 1000 条。单响应最多 2 MiB、JSON 深度 32/节点 20000、单文档展示 8192 字符/页面 256 Ki 字符；超限明确失败或未展开。JSON 保留数值原文，但不会从 JSON 推断时间/二进制或恢复服务端已丢失精度。网络读取 10 秒、整个请求 12 秒截止；取消关闭 TLS socket，但系统 DNS/初始 TCP 连接不保证立即中断，服务端查询不保证停止。认证头 String 在会话内存保留至断开，无法保证 JVM 字符串擦除，不写磁盘或日志。仅对列出的服务版本与系统测试组合给出证据。

OpenSearch 首次 JVM 验收曾出现一次 `Unexpected end of file from server`（网络断连），带日志复测及随后十轮读取未再现；根因尚未确认。保留失败 XML/日志，客户端会关闭会话并提示网络失败，不自动重试。长时间弱网和服务器断连稳定性仍需后续验证。

当前搜索 runner 对失败采取断开策略，非法 DSL 等本地校验失败也可能需要重新连接；尚未实现保留搜索草稿的多标签编辑体验。

服务器扫描不是全服务器资产清单：SQL 和 MongoDB 列表受账号可见性限制，PostgreSQL 需要可访问入口库，Redis/Valkey INFO keyspace 不含空库，搜索只列出范围内普通索引。扫描完成后会关闭临时连接，选库后重新认证；不跨用户等待持有事务。库名的现有限制仍在，列表中的不支持名称不可选择。具体时限与取消边界见 WORKSPACE。

OpenSearch 受限账号可能拒绝默认 `*` 的目录扫描，即使能读取指定索引。当前夹具的单索引 reader 正是如此；填写已授权的扫描范围后可枚举。客户端保留权限失败提示，不自动扩大权限或将拒绝当作空列表。Elasticsearch 与 OpenSearch 的目录可见性策略不能相互推断。

V0.7.2 调整连接导航与外观，未实现 DBeaver 全部功能；对象树、多 SQL 标签、完整上下文补全、ER 图、SSH 隧道仍需后续开发。完整九引擎 TLS 矩阵证据来自 V0.7.1；本轮只重跑报告列出的用例。

V0.8.0 密码密钥仅在此设备 Android Keystore。卸载、系统密钥丢失或设备迁移后不能保证恢复，需重新输入；未增加生物认证、应用锁或凭据导出。Android 8/11 模拟器验证不代表所有厂商 Keystore/真机。网格当前按单个单元格预览提交，不支持多格粘贴、批量提交、Excel 公式或整表加载。补全限本地已加载元数据；表结构能力矩阵中的只读引擎仍不可写。

V0.8.1：表收藏最多 100 项，仅当前 SQL 引擎的表/视图，不含集合/键/索引；必须先连接原连接，打开收藏可切换 SQL Server/MySQL/MariaDB 的库。PostgreSQL 每连接一库。改服务器、账号或复制连接后原收藏不能用于新目标，删除连接不会删除收藏，可在收藏页手动移除。表被同名重建时重新查询当前元数据，任何写入仍需新预览确认。数据库对象列表遵守既有元数据上限，默认 Schema 无表时需选择其它 Schema。

V0.9.0：AI 仅上述三种文本协议和独立单次问答；19 个国内外服务预设不代表逐家调用验证，专用认证 / Responses / 音视频 / 工具调用仍未接入。详见 AI_ASSISTANT。没有供应商真实密钥计费测试。字段组切换重新查询当前页，不是数据库快照；宽表仍只读，大字段仍按现有预算标记未加载，不提供全值按需读取或无限整表加载。

V0.9.1 的字段属性只展示驱动现有元数据；暂不支持字段定义修改、完整默认表达式、索引 / 外键管理或多查询标签。AI 配置仅在设置页，离开前须保存，未保存的表单不跨页面保留。

V0.10.0：实时 AI 默认关闭，开启后发送用户授权范围内的后续 SQL，可能有供应商费用。没有真实供应商计费/所有模型验收。缩放不增加服务器行数或字段读取预算。界面取消测试标签不表示 Release、正式签名和真机门禁已完成。

V0.11.0：表筛选最多 8 个 AND 条件；UI 每次选择一个主排序，底层最多 3 个，均追加主键。非文本包含匹配、复杂类型比较、任意 WHERE、OR 分组尚未开放。AI 表操作只支持 SQL 表受限查询和 SQL Server 单条写入预览，必须批准上下文并确认提交；不支持批量、跨表、任意 SQL 或自动多步代理。模型可能误解需求，提交预览显示实际目标与变更供核对。

## V0.12.0 工作状态边界

工作视图、布局、SQL 草稿和查询历史仅在进程内限量记忆，进程退出后清除；不保存数据行或待提交写入。真正进入后台（包括系统文件选择器）仍断开，可显式重新连接恢复。旧表结构变化可能使原筛选失效，会显示恢复失败并保留对象选择入口。多标签、批量暂存变更、其它引擎 CRUD、SSH、整表导入导出尚未实现。AI 预览开启的是本次连接编辑模式，取消预览后可通过“退出编辑”关闭；没有自动执行模型 SQL。

## V0.12.1 本轮范围

修复无 rowversion 的 SQL Server float/real 表编辑；未解除无主键、触发器、超过安全列数、大字段不完整等保护，生成列/标识列仍不可改。未访问用户 dbo.iclock_transaction，实际业务库最终是否可编辑仍取决于完整元数据与权限。当前模拟表覆盖主键、时间、浮点与 NULL。

新增内存内普通聊天，未实现持久化会话、流式输出、附件或模型工具调用。三个协议使用本地合成 HTTPS 上游验证，不能代替真实供应商账户/地区/计费验证。

本版 API26 回归已完成；API30 两次软件模拟器启动出现系统界面/服务故障及启动卡住，当前 APK 的 Android 11 验证未完成。历史版本 API30 通过不作为本版结果。详见本版 TEST_REPORT 与 diagnostics。
