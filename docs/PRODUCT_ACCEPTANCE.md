# 移动数据库管理工具的完成标准

用户最新目标是持续开发为真正的移动数据库管理工具，覆盖主流引擎并保留 SQL Server。上传的原始规划是背景与初始路线，当前范围以 DATABASE_SCOPE、ROADMAP 和实测能力矩阵为准。V0.4.0 是可安装的阶段版本，不是最终版。

| 使用任务 | V0.4.0 状态 | 最终发行前仍需完成 |
|---|---|---|
| 在手机管理连接 | 卡片搜索、复制、删除确认、按引擎配置、证书设置、连接状态 | IPv6、按需 SSH/云认证、更多网络与小屏/大字体验收 |
| SQL 日常查询 | 五种 SQL/文件引擎的对象、列、主键、分页与受限 SELECT | 其它主流 SQL 引擎、复杂类型、执行计划、按引擎评估更多查询语法 |
| 键值数据库 | Redis / Valkey 六类键的有界只读浏览、游标、TTL | 受控编辑/TTL 修改、集群和更多数据类型 |
| 文档、搜索、分析、时序和图 | 独立接入范围已列出，尚未实现 | 真实协议、对应数据模型和工作台，各引擎单独实连验收 |
| 数据维护 | SQL Server 测试会话的确认式单行增删改 | 其它引擎的定位键/绑定/并发冲突/权限/事务独立实现；生产变更策略 |
| 复用与交付查询结果 | 本机 SELECT 收藏、手动载入、当前页 CSV 确认导出 | 受控全表导出、导入预览与错误处理；不得把 CSV 冒称数据库备份 |
| SQL/对象管理 | 暂无任意写 SQL/DDL | 结构/索引浏览、风险明确的 DDL 和事务流程，按引擎实现 |
| AI 辅助 | 禁用占位 | 自选服务、授权上下文、草稿/解释；数据库操作不依赖 AI |
| 可发行性 | Debug 构建及测试证据，连续签名覆盖升级，完整源码归档 | Release/R8、最终包名/正式签名、arm64 真机、长期稳定性与弱网性能 |

每个引擎必须明确服务器版本、认证方式、TLS 正反例、对象/查询/类型边界、超时取消和实际 Android 测试结果。兼容协议产品需要独立测试；不能给数据库名称换一个图标就宣称支持。没有测试环境或授权条件的项目保持“未验证”，不进入已支持列表。

优先补齐 MongoDB、Elasticsearch/OpenSearch、ClickHouse，再推进企业/国产数据库和已接入引擎编辑能力；同时继续解决 Release 驱动适配。最终完成与否由上表的实际验收决定，不以版本名称或连接目录数量决定。
