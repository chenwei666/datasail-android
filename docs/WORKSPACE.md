# V0.11.0 筛选排序与 AI 表操作

在表格点击列名或上方“筛选 / 排序”。选择字段和运算符，输入原始值后应用；可升序、降序或恢复主键顺序。已有条件显示在表格上方，点击可修改/移除，或“清除条件”恢复整表浏览。不同条件同时满足（AND），同一列可同时设置上下界；NULL 与空字符串分别处理。包含/开头匹配按文字处理 `%`、`_` 等符号，不把输入当作 SQL。筛选在服务端执行，之后每页读取最多 100 行；不是只筛选当前页。刷新、翻页和提交修改保留条件。如果修改后的值不再满足条件，该行会从结果中消失。无主键仍只显示首批，排序与分页不是数据库快照。

列头显示升降序箭头及筛选标记；缩放时行距、字号和内边距同步变化，系统大字体也会计入行高。文本、数值和常见日期时间支持值筛选；复杂/二进制字段仅提供 NULL 筛选，SQLite 使用列亲和性处理绑定文本。SQL Server 时间筛选保留字段精度，其他 JDBC 引擎 time 值筛选目前为整秒，日期格式见输入提示。SQL 编辑器继续可执行已有受限只读查询。

自然语言操作：先打开目标表 → AI 助手 → “操作当前表” → 描述需求 → 预览并确认发送。例如“查找 id 等于 42 的记录，按时间倒序”。查询结果在本机显示，点击“查看表格结果”即可浏览。新增/修改/删除需勾选“允许为当前表生成写入预览”，然后检查目标、主键、原值/新值再确认提交。此选项明确授权本次开启当前会话编辑；切换目标后失效。每次写入一条，匹配零条或多条均拒绝。AI 不能自行跨库跨表、执行任意 SQL、批量操作或 DDL；目前写入仅 SQL Server，其他 SQL 引擎只查询。

# V0.10.0 工作台操作

连接后，从搜索面板选择表。「数据」用于浏览与编辑；「SQL 编辑器」始终是顶部固定页签；「表结构」搜索列和查看属性。数据库和 Schema 入口保持在页签上方，刷新和分页固定在底部。

SQL 输入 WHERE 或 FROM 后显示当前已加载字段或表；Tab 接受首项，没有候选时缩进。实时 AI 使用设置中的服务，默认关闭。开启前预览端点、SQL 与可选表结构，确认后包括随后输入的新 SQL 都会在停顿时发送；勿输入秘密，可能有 API 费用。不会发送数据行，不自动执行。离开 SQL 页或变更目标 / 模型 / 表结构后关闭。接受 AI 建议仅替换草稿。

# V0.8.0 移动工作流

首页点击“新建连接”，搜索并选择已接入的引擎，填写对应参数。Redis / Valkey 默认端口 6379、ACL 用户 default、数据库编号 0；实际 TLS 端口、用户和数据库范围以服务器配置为准。SQLite 只需选择一致性文件。保存后可按名称、主机、引擎搜索连接卡片，打开连接并输入密码。证书设置支持系统 CA、连接专用 CA 或显式核对后的服务器证书指纹，操作见 [CERTIFICATE_TRUST](CERTIFICATE_TRUST.md)。删除连接需确认；不会删除服务器数据。

## 先扫描服务器，再连接数据库

1. 选择引擎，填写名称、服务器、端口、用户名及密码，核对 CA 并确认访问授权。目标数据库可暂时留空。
2. 点击“连接服务器并扫描”。扫描连接只读取元数据，完成后关闭；不会提前进入工作台。
3. 筛选列表，点击目标；下方目标字段随之更新。点击“连接数据库”，重新登录所选库并进入工作台。可显式保存所选目标的连接配置，密码默认不保存，可勾选“在此设备保存密码”，保存或连接时加密写入。

| 引擎 | 扫描含义 |
|---|---|
| SQL Server | 用账号默认库登录，查询当前可访问且在线的库；账号默认库不可访问时可手动填写目标直接连接 |
| MySQL / MariaDB | 不指定数据库登录，读取 SHOW DATABASES 的可见库 |
| PostgreSQL | 先登录入口库（默认 postgres，可修改），列出非模板、允许连接且当前账号具有 CONNECT 权限的库；实际连接还受 HBA 等限制 |
| MongoDB | 在独立认证库认证，读取 authorizedDatabasesOnly 列表，不要求全服务器 listDatabases 管理权限 |
| Redis / Valkey | 读取 INFO keyspace；仅显示有键的编号，不代表全部配置库。需要 INFO keyspace 权限，空库可手动填写 |
| Elasticsearch / OpenSearch | 按扫描范围（默认 *）读取普通索引；账号需要相应索引监控权限，可缩小范围 |
| SQLite | 本机文件选择器，无服务器扫描 |

扫描列表最多显示 200 项；SQL/MongoDB/键值超出时提示部分列表，搜索引擎超限需缩小范围。暂不支持的库名会显示但不可选择（现有库名限制仍为字母、数字、下划线、横线）；前后空格也不会被修剪成另一个目标。扫描失败、列表为空、筛选无结果分别提示，均允许手动填写已知目标；不会把权限不足显示为空服务器。

修改服务器、端口、用户、认证库、CA、扫描范围或密码时作废旧扫描结果；取消、离开页面或进入后台也作废回调并关闭扫描连接。未保存的密码仅保留在当前页面内存中供扫描后连接使用；选择保存时写入独立加密存储，不进入连接配置 JSON。JDBC 登录过程中底层驱动尚未返回连接时，取消会作废结果，驱动依赖自身连接/登录超时收尾；不宣称立即中断系统 DNS 或服务端执行。

连接成功自动进入对应工作台。SQL 引擎保留对象/列/主键/查询/分页；Redis/Valkey 显示独立键值界面，匹配模式使用服务器 glob 语法。SCAN 的 COUNT 是提示，空页和重复键可能出现，游标不是快照。改变匹配模式必须重新扫描。键的原始字节用于后续请求，不从显示文本重建。

键值预览支持 string、list、hash、set、zset、stream。字符串最多前 2048 字节；列表、有序集合和 Stream 前 100 项；哈希/集合有游标续页。TTL -1 表示不过期，-2 表示不存在。类型、长度、TTL 和内容分次读取，不是原子快照。无任意命令、脚本、写入、Sentinel、集群重定向和模块类型；MOVED/ASK 明确不支持。单响应 256 KiB、单 bulk 8192 字节、4096 节点、8 层嵌套，超限或错误关闭会话，不截断后继续复用协议流。登录总预算 30 秒；每次扫描/预览 10 秒（网络写入也受 socket 关闭截止时间约束；系统 DNS 调用自身可能较慢）。建议服务端 ACL 只授予如下命令：

`ping select scan type pttl strlen getrange llen lrange hlen hscan scard sscan zcard zrange xlen xrange`

SQL 工作台“收藏查询”要求确认草稿不含密码/密钥；收藏最多 100 条、每条 16000 字符，只在本机存储。收藏页按类型匹配当前连接，载入后仍需核对目标并手动执行，不在连接恢复后自动提交。

“导出当前页 CSV”先确认连接和当前页行数，再选择保存位置。UTF-8、CRLF、字段双引号转义，NULL 为 `\N`，文字以反斜杠开头时增加一个反斜杠；有公式风险的文字前加单引号。保留数值原始十进制文字，电子表格导入时仍应指定工号等列为文本。二进制为 `0x` 十六进制。未完整加载字段的页面不能导出；最多当前 100 行，不是整表/数据库备份。系统文件选择器进入后台会断开会话，已确认的页面快照用于文件写出，不发起新查询。失败可能留下部分文件，界面会明确提示。键值内容暂不支持 CSV。

## SQL 工作台

连接页先选择数据库类型；网络数据库填写地址、账号并按连接选择可信 CA。SQL Server 支持原有单行编辑，MySQL/MariaDB/PostgreSQL 当前只读。PostgreSQL 一个连接对应一个数据库，切换其他库需另建连接；MySQL/MariaDB 可以在已授权列表中切库。

SQLite 通过系统选择器导入不超过 64 MiB 的完整一致性副本。请先用原数据库工具导出为非 WAL 模式，不能只复制活跃 WAL 数据库的主文件。应用对副本执行格式与 quick_check 检查，并只读打开；不修改或写回源文件。SQLite 类型按单元格动态显示；超大单元格可能受 Android CursorWindow 限制而查询失败。

MySQL/MariaDB/PostgreSQL 每次操作独立执行服务端只读事务，随后回滚，不跨人类等待持有事务；不开放任意写 SQL。SQL 过滤额外拒绝 MySQL 可执行注释、美元引用和反斜线歧义写法，使用标准引用。数组、文档、XML 等复杂 JDBC 类型标记未加载。

以下单行编辑与 rowversion 说明仅适用于 SQL Server：

1. 连接页填写名称、服务器 DNS/IPv4、端口、数据库、用户名。可以保存、选择、复制或删除连接元数据；密码可选择加密保存，复制连接不携带密码。数据库名暂限字母、数字、下划线和连字符。
2. 默认使用系统 CA。私有证书通过系统选择器导入有效 X.509 CA（64 KiB 上限），核对 SHA-256 指纹后选择到当前连接。只保存公钥证书，不保存私钥。默认模式下 SQL Server 强制链校验及 SAN 主机名校验，不再使用依赖桌面 JNDI 的 CN 回退；仅 CN、无匹配 SAN 的证书默认拒绝。显式证书指纹模式可用于此类服务器，但须独立核对证书并确认例外；仍强制 TLS、指纹相同及证书有效期。
3. 工作台依次选择数据库、Schema、表/视图。显示字段、类型、主键、自增与 NULL 属性；每页至多 100 行/64 列，SQL Server 文本字段最多 4000 个 UTF-16 单元（其它 JDBC/SQLite 仍为 2048），二进制最多 256 字节，总文本预算 256 Ki 字符。超限字段明确标为未加载，不能编辑。主键排序分页在并发变化下不是快照；无主键仅显示首批。
4. SELECT 查询结果只读，不推断 JOIN 或聚合可写性。拒绝多语句、变量、SELECT INTO、NEXT VALUE、远程行集、CTE 等。本地过滤只是保守语法门禁，不能替代 SQL Server 权限。生产连接务必使用服务端只读账号，函数和视图的权限仍由服务器决定。
5. 测试会话可手动启用写入。可编辑类型限文本、整数、精确小数和布尔；不修改主键、自增、计算列或 rowversion。视图、无主键、启用触发器、超过 64 列、不支持的主键，以及无 rowversion 且不能精确比较整行的表均只读。新增时未勾选列使用服务器默认值或 NULL；必须填写无默认值的必填列。
6. 编辑选中行或新增记录后生成变更预览；删除也必须预览。预览显示服务器、库、Schema、环境、主键、前后值和参数化 SQL。文本加引号以区分文字 `"NULL"`、空字符串 `""` 与数据库 NULL。预览绑定会话、对象身份、原行和参数，只使用一次、有效 2 分钟；切库、刷新、查询、模式变更或断开使旧预览失效。
7. 点击确认后才开启短事务。事务内持有表级共享锁并核对元数据，防止验证和 DML 之间新增触发器/更换表；随后按主键+rowversion 或整行原值做乐观并发检查。文本按原始字节匹配，避免排序规则忽略大小写/尾空格。匹配数必须为 1，否则回滚。表锁可能短暂阻塞其它写入，本版适用于小规模授权测试。
8. 已知提交结果后重新读取当前页；刷新失败明确提示并断开，不会把编辑前缓存当作数据库新值。断网、超时、取消或提交确认丢失均可能显示“执行结果未知，需核对”，不会自动重放。可确认的数据库错误回滚并提示。

连接超时 5 秒、查询超时 10 秒、锁等待 5 秒、socket 15 秒。会话由单一有界后台线程串行访问；取消同时请求 Statement.cancel 和连接关闭。进入后台/旋转会断开，密码清空，不提供后台常驻会话。导入证书使用系统选择器，无全部文件权限。连接元数据采用带版本号的 AtomicFile；读取失败禁止覆盖，V0.1.0 无持久配置需要迁移。

仍未实现：服务器端对象搜索、大字段按需读取、复杂类型编辑、任意写 SQL、DDL、事务工作台、批量编辑和 AI。异常结果需人工核对，数据库账号应按实际用途最小授权。

## MongoDB 文档工作台

新建连接选择 MongoDB，填写服务器、端口（27017）、目标数据库、用户名及认证数据库（通常 admin；不是目标库的同义词）。导入 CA 后核对指纹，输入密码并确认已获授权。当前只接受单个 DNS/IPv4 地址、TLS、SCRAM-SHA-256。建议为目标库授予 read 角色。

连接成功后点集合读取第一页；输入 JSON 筛选后点“重新查询文档”，如 `{"name":"0007"}` 或 `{"_id":{"$oid":"0123456789abcdef01234567"}}`。下一页沿当前服务器游标读取，不通过累积 skip 扫描。改变筛选后必须重新查询。列表标明结果实际集合与条件，不能将编辑中的条件误当成已执行条件。

canonical Extended JSON 明确区分 `$numberLong`、`$numberDecimal`、`$oid`、`$date`、`$binary`、NULL 和空字符串。每页最多 100 文档，超限内容会显示“未展开”，不会冒充完整文档。当前不支持文档写入/聚合/导出。游标过期、取消或后台断开后需重新连接、查询；不自动恢复或重放。

## 搜索工作台

Elasticsearch / OpenSearch 连接填写服务器、9200 端口、索引范围（如 `logs-*`）、Basic 用户名和密码及可选 CA。服务账号需读取、索引监控和映射查看权限；客户端只读限制不能替代服务端权限。连接后选择索引，查看 `_mapping` 或输入 query 内部条件，如 `{"term":{"code":"0007"}}`。结果显示实际索引和条件，编辑条件后禁用旧结果续页；重新搜索才应用新条件。搜索与 SQL 收藏、SQL 写入、文档游标相互隔离。

分页不是快照，页面变化、断网或超限后手动重查；应用不自动重放；平台 HTTP 内部连接行为由系统实现决定，开放端点均只读。映射和文档可选择复制，尚无搜索结果导出。具体边界见 KNOWN_ISSUES。

OpenSearch 受限账号可能拒绝默认 `*` 的目录扫描，即使能读取指定索引。当前夹具的单索引 reader 正是如此；填写已授权的扫描范围后可枚举。客户端保留权限失败提示，不自动扩大权限或将拒绝当作空列表。Elasticsearch 与 OpenSearch 的目录可见性策略不能相互推断。


## V0.8.0 桌面数据库工具式工作流

连接选择使用紧凑引擎列表。勾选保存密码后，“保存配置”或“连接数据库”会保存元数据并加密密码；扫描不会自动保存。再次打开同一服务器/账号的连接自动填入，复制连接不携带密码。取消勾选后保存会移除该连接密文；“忘记密码”立即移除。密码保存失败会明确提示，不能据此认为下次一定自动填入。

SQL 工作台默认“数据浏览”；选择库、Schema 和表后显示网格，横向查看列、网格内纵向查看当前页。列标题、行号、斑马纹、精确值及 NULL/空字符串分别保留。点击选中单元格，双击或点击“编辑单元格”进入原位输入，预览后再确认提交。一次只编辑一个单元格，切换前先预览或取消。SQL Server 测试会话需显式打开写入，主键/自增/不支持类型不可改；生产连接、无主键、视图、触发器表和任意 SQL 查询结果不可通过网格写入。其它 SQL 引擎当前仅使用此表格浏览。不是 Excel 文件编辑器，没有公式、多格粘贴或批量写入。

已知修改结果后刷新当前页；刷新失败会保留明确的修改结果并断开，用户重新连接核对，绝不自动重放写入。超时导致 UNKNOWN 时不刷新冒充提交完成。

“SQL 编辑器”包含本地补全；输入前缀后按外接键盘 Tab、屏幕“Tab 补全”或候选按钮。仅使用当前已加载的表名、当前表字段和常用关键字，不是完整 SQL 语言服务器，不解析所有 JOIN 别名或加载全库结构。补全后仍由用户手动执行支持的单条 SELECT。

设置中的主题、网格密度/字号/类型显示、编辑器字号/补全和新连接生产默认值写入本机。新默认值不修改已有连接。清除密码与恢复设置都有确认；恢复设置不清除密码、连接或收藏。AI 尚未接入，暂无虚假的 AI 配置或自动执行入口。

## V0.8.1：连接后浏览与表收藏

首页“历史连接”点击“连接并进入工作台”，使用此连接在本机保存的密码；没有保存或解密失败会进入配置填写。SQLite 副本无需密码。连接不会自动开启可写权限。

SQL 工作台进入后自动加载目录及默认 Schema（dbo/public/main/当前库）。数据库和 Schema 选择器位于上方，下方直接显示表/视图，点击对象查看数据。空列表与加载失败分别提示，可使用“刷新数据库和对象”；受限账号无法枚举库时仍可浏览已认证当前库。

打开表后点击“收藏此表”；底部“收藏”页可以按表名/库/Schema/连接名搜索并打开、取消收藏。收藏需要原连接端点与账号一致，跨库时使用现有切库机制，再重新解析对象元数据，不用旧 object_id 直接读取。生产只读和写入预览保护继续生效。收藏只存在本机，最多100项，不会保存密码或数据行。

## V0.9.0 表格与 AI

打开表后可切换字段组（每组 64 列），再浏览行分页；顶部显示总字段数。全屏表格、列宽切换、换行、列显隐与整行详情提升可读性。超限字段仍明确标记未加载，整行详情仅显示当前字段组，不冒充完整大字段。AI 使用流程见 [AI_ASSISTANT](AI_ASSISTANT.md)。

## V0.9.1 字段属性

打开 SQL 表后点「查看表结构」，按字段名或类型筛选已加载的全部字段，勾选「仅主键」，或复制原始字段名。列表显示元数据属性，长度 / 精度未提供时明确标记。这里不编辑结构、不提交 DDL，也不把默认值存在标志当作完整默认表达式。列表滚动和筛选不额外读取数据行，数据浏览的行 / 列预算保持不变。

AI 的地址、密钥、协议、模型和开关统一在「设置 → AI 服务与模型」管理；AI 助手页仅用于问答、上下文预览和草稿。

## V0.12.1 编辑状态与浮点字段

“结束编辑”表示连接已允许写入，不代表所有表都可修改。表格上方现在直接显示表的只读原因，选中字段时显示字段限制。主键、标识列/生成列、触发器、未完整加载字段等规则仍有效。

SQL Server float/real 使用驱动数值读取和可往返字符串显示，参数按 real/float(53) 转换，原值以二进制比较。没有 rowversion 的经纬度表不再仅因浮点字段变为只读。并发变更哪怕只差相邻浮点值，也不会覆盖；NULL 与 0 分别处理。输入超出类型范围或往返精度时拒绝，而非静默舍入。无法安全比较的其它字段仍列出具体字段名。

## V0.12.2 大文本声明与行编辑

`nvarchar(max)` / `varchar(max)` 的声明容量不再决定整表只读。无 rowversion 的表仍逐字段校验完整原值；主键、权限、触发器等限制继续生效。点击「编辑模式」并确认后，双击非主键字段，修改、预览，再确认提交。无需新增 rowversion 或改表结构。

文本单字段最多完整加载 4000 个 UTF-16 单元，每页合计仍有 262144 字符预算；实际超限的字段显示未完整加载，其所在行不能修改或删除，界面列出对应字段名。这不同于仅声明 MAX：NULL、空串和预算内文本均可比较。4000 字符内输入不会因旧 2048 读取限制而在刷新后变为未加载。其它行完整加载时仍可编辑。
