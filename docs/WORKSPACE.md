# V0.5.0 移动工作流

首页点击“新建连接”，搜索并选择已接入的引擎，填写对应参数。Redis / Valkey 默认端口 6379、ACL 用户 default、数据库编号 0；实际 TLS 端口、用户和数据库范围以服务器配置为准。SQLite 只需选择一致性文件。保存后可按名称、主机、引擎搜索连接卡片，打开连接并输入密码。证书设置支持系统 CA 或连接专用 CA。删除连接需确认；不会删除服务器数据。

连接成功自动进入对应工作台。SQL 引擎保留对象/列/主键/查询/分页；Redis/Valkey 显示独立键值界面，匹配模式使用服务器 glob 语法。SCAN 的 COUNT 是提示，空页和重复键可能出现，游标不是快照。改变匹配模式必须重新扫描。键的原始字节用于后续请求，不从显示文本重建。

键值预览支持 string、list、hash、set、zset、stream。字符串最多前 2048 字节；列表、有序集合和 Stream 前 100 项；哈希/集合有游标续页。TTL -1 表示不过期，-2 表示不存在。类型、长度、TTL 和内容分次读取，不是原子快照。无任意命令、脚本、写入、Sentinel、集群重定向和模块类型；MOVED/ASK 明确不支持。单响应 256 KiB、单 bulk 8192 字节、4096 节点、8 层嵌套，超限或错误关闭会话，不截断后继续复用协议流。登录总预算 30 秒；每次扫描/预览 10 秒（网络写入也受 socket 关闭截止时间约束；系统 DNS 调用自身可能较慢）。建议服务端 ACL 只授予如下命令：

`ping select scan type pttl strlen getrange llen lrange hlen hscan scard sscan zcard zrange xlen xrange`

SQL 工作台“收藏查询”要求确认草稿不含密码/密钥；收藏最多 100 条、每条 16000 字符，只在本机存储。收藏页按类型匹配当前连接，载入后仍需核对目标并手动执行，不在连接恢复后自动提交。

“导出当前页 CSV”先确认连接和当前页行数，再选择保存位置。UTF-8、CRLF、字段双引号转义，NULL 为 `\N`，文字以反斜杠开头时增加一个反斜杠；有公式风险的文字前加单引号。保留数值原始十进制文字，电子表格导入时仍应指定工号等列为文本。二进制为 `0x` 十六进制。未完整加载字段的页面不能导出；最多当前 100 行，不是整表/数据库备份。系统文件选择器进入后台会断开会话，已确认的页面快照用于文件写出，不发起新查询。失败可能留下部分文件，界面会明确提示。键值内容暂不支持 CSV。

以下为 SQL 工作台原有操作边界：

## SQL 工作台

连接页先选择数据库类型；网络数据库填写地址、账号并按连接选择可信 CA。SQL Server 支持原有单行编辑，MySQL/MariaDB/PostgreSQL 当前只读。PostgreSQL 一个连接对应一个数据库，切换其他库需另建连接；MySQL/MariaDB 可以在已授权列表中切库。

SQLite 通过系统选择器导入不超过 64 MiB 的完整一致性副本。请先用原数据库工具导出为非 WAL 模式，不能只复制活跃 WAL 数据库的主文件。应用对副本执行格式与 quick_check 检查，并只读打开；不修改或写回源文件。SQLite 类型按单元格动态显示；超大单元格可能受 Android CursorWindow 限制而查询失败。

MySQL/MariaDB/PostgreSQL 每次操作独立执行服务端只读事务，随后回滚，不跨人类等待持有事务；不开放任意写 SQL。SQL 过滤额外拒绝 MySQL 可执行注释、美元引用和反斜线歧义写法，使用标准引用。数组、文档、XML 等复杂 JDBC 类型标记未加载。

以下单行编辑与 rowversion 说明仅适用于 SQL Server：

1. 连接页填写名称、服务器 DNS/IPv4、端口、数据库、用户名。可以保存、选择、复制或删除连接元数据；每次连接重新输入密码。数据库名暂限字母、数字、下划线和连字符。
2. 默认使用系统 CA。私有证书通过系统选择器导入有效 X.509 CA（64 KiB 上限），核对 SHA-256 指纹后选择到当前连接。只保存公钥证书，不保存私钥。SQL Server 强制链校验及 SAN 主机名校验，不再使用依赖桌面 JNDI 的 CN 回退；仅 CN、无匹配 SAN 的证书拒绝。
3. 工作台依次选择数据库、Schema、表/视图。显示字段、类型、主键、自增与 NULL 属性；每页至多 100 行/64 列，字段最多 2048 字符或 256 字节二进制，总文本预算 256 Ki 字符。超限字段明确标为未加载，不能编辑。主键排序分页在并发变化下不是快照；无主键仅显示首批。
4. SELECT 查询结果只读，不推断 JOIN 或聚合可写性。拒绝多语句、变量、SELECT INTO、NEXT VALUE、远程行集、CTE 等。本地过滤只是保守语法门禁，不能替代 SQL Server 权限。生产连接务必使用服务端只读账号，函数和视图的权限仍由服务器决定。
5. 测试会话可手动启用写入。可编辑类型限文本、整数、精确小数和布尔；不修改主键、自增、计算列或 rowversion。视图、无主键、启用触发器、超过 64 列、不支持的主键，以及无 rowversion 且不能精确比较整行的表均只读。新增时未勾选列使用服务器默认值或 NULL；必须填写无默认值的必填列。
6. 编辑选中行或新增记录后生成变更预览；删除也必须预览。预览显示服务器、库、Schema、环境、主键、前后值和参数化 SQL。文本加引号以区分文字 `"NULL"`、空字符串 `""` 与数据库 NULL。预览绑定会话、对象身份、原行和参数，只使用一次、有效 2 分钟；切库、刷新、查询、模式变更或断开使旧预览失效。
7. 点击确认后才开启短事务。事务内持有表级共享锁并核对元数据，防止验证和 DML 之间新增触发器/更换表；随后按主键+rowversion 或整行原值做乐观并发检查。文本按原始字节匹配，避免排序规则忽略大小写/尾空格。匹配数必须为 1，否则回滚。表锁可能短暂阻塞其它写入，本版适用于小规模授权测试。
8. 提交确认成功后提示刷新；不会把编辑前缓存当作数据库新值。断网、超时、取消或提交确认丢失均可能显示“执行结果未知，需核对”，不会自动重放。可确认的数据库错误回滚并提示。

连接超时 5 秒、查询超时 10 秒、锁等待 5 秒、socket 15 秒。会话由单一有界后台线程串行访问；取消同时请求 Statement.cancel 和连接关闭。进入后台/旋转会断开，密码清空，不提供后台常驻会话。导入证书使用系统选择器，无全部文件权限。连接元数据采用带版本号的 AtomicFile；读取失败禁止覆盖，V0.1.0 无持久配置需要迁移。

仍未实现：服务器端对象搜索、大字段按需读取、复杂类型编辑、任意写 SQL、DDL、事务工作台、批量编辑、密码记忆和 AI。异常结果需人工核对，数据库账号应按实际用途最小授权。

## MongoDB 文档工作台

新建连接选择 MongoDB，填写服务器、端口（27017）、目标数据库、用户名及认证数据库（通常 admin；不是目标库的同义词）。导入 CA 后核对指纹，输入密码并确认已获授权。当前只接受单个 DNS/IPv4 地址、TLS、SCRAM-SHA-256。建议为目标库授予 read 角色。

连接成功后点集合读取第一页；输入 JSON 筛选后点“重新查询文档”，如 `{"name":"0007"}` 或 `{"_id":{"$oid":"0123456789abcdef01234567"}}`。下一页沿当前服务器游标读取，不通过累积 skip 扫描。改变筛选后必须重新查询。列表标明结果实际集合与条件，不能将编辑中的条件误当成已执行条件。

canonical Extended JSON 明确区分 `$numberLong`、`$numberDecimal`、`$oid`、`$date`、`$binary`、NULL 和空字符串。每页最多 100 文档，超限内容会显示“未展开”，不会冒充完整文档。当前不支持文档写入/聚合/导出。游标过期、取消或后台断开后需重新连接、查询；不自动恢复或重放。
