# AI 助手（V0.9.0）

AI 是可关闭的独立文本助手，未配置时不影响数据库。它生成解释、建议与 SQL 草稿，不执行 SQL，也没有数据库工具调用能力。

## 配置和使用

1. 打开「AI 助手 → 管理服务与模型 → 添加服务」。选择预设或自定义，核对服务商提供的 HTTPS API 基础地址及地区。路径含版本（例如 `/v1`），不要填写单次聊天接口、网页地址或带密钥的 URL。
2. 填入自己的 API 密钥，保存服务，开启 AI；点击「获取上游模型」。模型列表来自该端点，最多五页 / 1000 个；支持筛选。服务不提供 models 接口或使用部署 ID 时，手填模型 ID。
3. 选择模型后保存服务。不同平台普通 API、Coding Plan、国内 / 国际站可能使用不同端点和账户权限。可保存 24 个独立服务并切换。
4. 输入问题，按需勾选当前表结构或编辑器 SQL；预览中可直接脱敏，确认后才发送。本版每次为独立问答，不自动携带之前对话，不附加数据行、密码、服务器地址、整库结构或日志。
5. 回答中的单个 `sql` 代码块可载入 SQL 编辑器；本地重新判断查询规则，必须再确认替换草稿，并在工作台手动执行。目标 / SQL / 表结构变化后旧回答不能直接载入。当前编辑器不开放任意写 SQL。

现有和新连接默认禁止外部 AI；要发送当前连接上下文，在连接表单显式勾选允许并重新连接。保存禁止策略会立即阻止该连接后续 AI 请求。未连接时只提供通用解释，不假装知道数据库。

## 协议与预设的实际边界

| 协议 | 模型获取 | 文本生成 | 认证 |
|---|---|---|---|
| OpenAI 兼容 | GET `/models` | POST `/chat/completions`，非流式 | Bearer API key |
| Anthropic | GET `/models`，after_id 分页 | POST `/messages`，非流式 | x-api-key，版本 2023-06-01 |
| Gemini | GET `/models`，pageToken 分页，筛出 generateContent | POST `/models/{id}:generateContent` | x-goog-api-key |

预设包括 OpenAI、Claude、Gemini、DeepSeek、通义千问、豆包、智谱、Kimi、MiniMax、硅基流动、百度千帆、腾讯混元、Grok、OpenRouter、Groq、Mistral、Together、NVIDIA NIM、Perplexity。**预设仅帮助填写地址，不是逐供应商实测认证**。以账户提供的接口文档为准，地址可修改。

不支持任意“所有模型”：仅文本生成且须符合上述协议。AWS Bedrock / Vertex IAM、Azure 专有认证 / 部署接口、OpenAI Responses-only 模型、图片、音频、工具调用、流式响应及本地明文 HTTP 暂未实现。OpenAI 兼容请求使用 max_tokens=2048；只接受其它参数形式的模型可能拒绝，界面如实报告 HTTP 错误。模型列表可见不等于当前账号有调用权限。

本轮用独立 HTTPS 合成服务验证三种协议；没有使用供应商真实 API key，没有逐家在线计费调用验收，不能声称已实测所有国内外供应商。

## 数据与网络限制

- API 密钥使用独立 Android Keystore AES-GCM 密钥域，绑定服务 ID、协议和完整基础地址。地址变化不会复用旧密钥；配置文件无明文密钥。可清除单服务密钥或删除服务。问答只在内存，清空 / 进程退出不保留对话。
- HTTPS 平台证书与主机校验；拒绝所有重定向，不向其它地址转发认证，不支持信任全部。不跟随上游返回的 URL、工具或命令。
- 每次请求总截止 60 秒，连接 15 秒、读取 45 秒，响应 1 MiB，文本输入 / 输出各 24000 字符；输出限 2048 token。截断、工具或非文本结果不当作完整 SQL 草稿。
- 取消、离开 AI 页、后台或目标变化会关闭实际 TLS socket；不自动重试。模型内容 / 数据库上下文均不可信，系统规则不接受数据库文本覆盖。
- 用户主动输入或勾选的 SQL、字段名可能包含业务信息。预览供用户核对与手动脱敏，不宣称自动识别所有秘密。API 调用费用由上游账户承担。
