# 密码存储与边界（V0.8.0）

默认不保存。用户勾选“在此设备保存密码”，再保存配置或连接，才会写入；打开已保存连接自动填入但不自动连接。扫描操作、证书预览、复制连接不保存或转移凭据。忘记单连接密码或设置中确认全部清除会删除密文；全部清除也删除该应用专用 Keystore 密钥。

使用 AndroidKeyStore 生成 AES 密钥，AES/GCM/NoPadding 随机 IV 加密。密钥不可经应用 API 导出，不宣称必定硬件背书。密文在 noBackupFilesDir/passwords-v1，文件名为连接 ID 的 SHA-256；Android 备份和设备迁移规则也排除应用数据。连接 JSON/收藏/截图/日志/归档不保存密码。

认证附加数据使用长度前缀编码的连接 ID、数据库引擎、规范化主机/端口、账号、authSource。相同连接选择该服务器的另一个目标库可以复用账号密码；更换服务器、端口、类型、账号或复制连接不能复用。外部可见的绑定摘要不替代 GCM 验证。错误密文、丢失密钥会拒绝解密并提示重新输入，不回退明文，不自动删除尚存密文。

保存使用 AtomicFile；凭据写入和“清除”在 ViewModel 内串行化，避免先发起的保存晚于清除而重新生成密码。配置与密码是独立文件：元数据成功但密码失败时明确提示，不宣称整体原子事务。页面异步填入绑定请求代次与连接快照，修改输入、离开、后台后过期回调不得填回密码。

网络认证仍遵循当前 CA/证书指纹与 TLS 策略。保存密码不等于授权连接，也不会跳过访问授权勾选。进入后台断开，未保存的页面密码清空。内存 CharArray/编码缓冲尽力清零；Compose/JVM String 无法保证彻底擦除。没有新增应用锁或生物认证，任何能够解锁并进入应用的人可使用本机已保存连接；恢复设置不会清除已存密码，清除密码不会中断一个已经认证的前台会话。
